# Prompt para Cursor + Grok 4.7 — Rediseño 3D de HeadRace

## Objetivo

Quiero rediseñar completamente la interfaz visual de esta pantalla de **HeadRace**, tomando como referencia principal la imagen adjunta.

**IMPORTANTE:** no quiero solamente cambiar colores, CSS o agregar algunas imágenes. Quiero convertir la escena actual en una experiencia visual **3D de videojuego arcade de carreras**, mucho más inmersiva y cercana a un juego tipo kart racing moderno. La referencia visual debe ser la imagen adjunta.

Primero **analiza todo el proyecto existente**, identifica:

- framework utilizado
- estructura de componentes
- sistema actual de renderizado de la pista
- lógica de velocidad
- detección de obstáculos
- cámara/webcam
- minimapa
- contador de choques
- estado de la sesión
- controles actuales

Después implementa el rediseño sobre la arquitectura existente **sin romper la lógica funcional que ya existe**.

---

# 1. OBJETIVO VISUAL

La interfaz debe parecer un **juego 3D de carreras arcade**, inspirado visualmente en juegos como Mario Kart, pero **sin copiar personajes, logos, modelos o assets propietarios**.

La sensación debe ser:

- 3D
- colorida
- dinámica
- moderna
- divertida
- cinematográfica
- con sensación de velocidad
- profundidad de campo
- iluminación dinámica
- partículas
- sombras
- objetos con volumen
- escenario vivo

No quiero que se vea como una página web con una carretera dibujada.

Quiero que visualmente parezca una **pantalla real de un videojuego de carreras**.

---

# 2. ESCENA 3D

La carretera debe ser el elemento principal.

Crear una escena 3D donde tengamos:

- carretera con perspectiva
- varios carriles
- líneas de carril
- bordes de carretera
- guardarraíles
- zonas laterales
- vegetación
- montañas
- cielo
- iluminación dinámica
- objetos decorativos

La carretera debe dar sensación real de profundidad.

El vehículo del jugador debe estar en primer plano, visto desde atrás en tercera persona.

El kart debe tener:

- carrocería 3D
- ruedas visibles
- luces
- sombra
- pequeños efectos de partículas
- sensación de movimiento
- animación cuando acelera

El vehículo debe desplazarse continuamente hacia adelante y la carretera/escenario debe dar la sensación de movimiento.

---

# 3. ESCENARIO

Quiero un escenario tropical y colorido.

Agregar progresivamente:

- palmeras
- árboles
- arbustos
- montañas al fondo
- flores
- rocas
- carteles
- banderas
- barreras
- conos
- cajas
- elementos decorativos

Las palmeras deben aparecer a ambos lados de la carretera, con diferentes tamaños y posiciones para evitar que todo se vea repetitivo.

Utilizar generación procedural o reutilización eficiente de modelos cuando sea necesario.

Debe existir **parallax/depth**, de manera que los elementos cercanos se muevan más rápido que los elementos lejanos.

---

# 4. CICLO DÍA → TARDE → NOCHE

Uno de los elementos más importantes del rediseño es un **ciclo visual dinámico del escenario**.

La escena debe poder cambiar gradualmente entre:

## DÍA

- cielo azul
- sol visible
- iluminación fuerte
- sombras marcadas
- nubes
- ambiente tropical

## TARDE / ATARDECER

El ambiente debe cambiar progresivamente:

- cielo naranja/rosado
- luz cálida
- sol descendiendo
- sombras más largas
- iluminación dorada
- ambiente cinematográfico

## NOCHE

Debe aparecer:

- cielo oscuro
- luna
- estrellas
- iluminación azulada
- luces del kart
- luces de pista
- elementos luminosos
- mayor contraste

El cambio debe ser **gradual**, nunca un cambio brusco de escenario.

Quiero que visualmente se perciba que realmente está avanzando el tiempo.

Idealmente crear una variable similar a:

```ts
timeOfDay
```

que permita interpolar:

```text
DAY -> SUNSET -> NIGHT
```

y luego:

```text
NIGHT -> SUNRISE -> DAY
```

La transición debe afectar:

- skybox/background
- color ambiental
- iluminación
- sombras
- color de la carretera
- color de vegetación
- estrellas
- sol
- luna
- luces artificiales

# 5. SOL Y LUNA

Durante el día debe verse claramente el sol.

Durante el atardecer el sol debe moverse hacia el horizonte.

Durante la noche debe desaparecer el sol y aparecer la luna.

La luna debe tener un efecto de iluminación suave.

Agregar estrellas durante la noche.

Evitar que parezca simplemente un círculo pegado al fondo.

Debe integrarse visualmente con la escena.

---

# 6. NUBES

Agregar nubes dinámicas.

Las nubes deben tener movimiento muy lento para que el escenario se sienta vivo.

No deben distraer de la carretera.

---

# 7. EFECTOS DE VELOCIDAD

El usuario actualmente tiene un valor de velocidad, por ejemplo:

```text
90 km/h
```

Ese valor debe influir visualmente en la escena.

A mayor velocidad:

- aumentar motion blur simulado
- aumentar partículas
- aumentar sensación de desplazamiento
- hacer que el entorno pase más rápido
- aumentar efectos de viento

No quiero simplemente cambiar el número.

Quiero que la velocidad tenga **impacto visual real**.
